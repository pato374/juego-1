# Juego 1

Juego de cartas y botón rojo. Funciona en el navegador.

## Jugar solo (contra la IA)
Abre `index.html` con doble clic, o entra a la página de GitHub Pages del repositorio.

## Multijugador
Necesitas Node.js (https://nodejs.org). En una consola, dentro de esta carpeta:

    node servidor.js

Luego abre http://localhost:3000. La consola muestra los movimientos del Jugador 1 y el Jugador 2.
Si juegas desde otra página (por ejemplo GitHub Pages), escribe la dirección de tu servidor en
Configuración → Servidor.

## Archivos
- `index.html`: el juego completo
- `servidor.js`: servidor multijugador (sin dependencias)
